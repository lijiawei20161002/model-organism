## Historical experiments

The previous code, datasets, run outputs and notes are available at [the pre-cleanup snapshot](https://github.com/lijiawei20161002/model-organism/tree/b16a92e07270eaee6bc7edae8a9aa5f97f97a154). The report links to that fixed version and explains which artifacts were originally absent from Git.

To inspect the historical project in a separate directory:

```bash
git worktree add --detach ../model-organism-legacy b16a92e07270eaee6bc7edae8a9aa5f97f97a154
```
